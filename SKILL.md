# code-to-cinema · 代码映画

Films drawn in code. Nothing is generated by an image model. Every mark is a line you wrote, revealed over time as if someone were drawing it live.
The engine gives you: a `Plate` (a drawing that writes itself), hatching that turns a *tone function* into engraved shading, a pen nib that follows the newest stroke, paper, grain and gate-weave post, typed captions, a procedural soundtrack synced to the ink, and encoders for chat apps and X.

Styles live in `styles/`. Read the style file before you draw anything.

| style | file | looks like |
|---|---|---|
| Engraving 铜版画 | `styles/engraving.md` | Gustave Doré copperplate: sepia paper, black ink, cross-hatching, one warm lamp colour |
| Liyue 掐丝珐琅 | `styles/liyue.md` | pastel cloisonné garden at night: gold wire lays itself, enamel floods each cell, guzheng score. Set `style: 'liyue'` in `FILM` and use `engine/liyue/audio.cjs` |
| Awakening 37号觉醒 | `styles/awakening.md` | 1920s stop-motion reel: pencil and ink wash on ivory paper, poses that jump 8 times a second, specimen labels, paper caption cards, one wine red, a slam title. Set `style: 'awakening'` and use `engine/awakening/audio.cjs`. An 8 s demo is in `examples/typewriter` |

(More styles get added as new drawers.)

## 0 · Setup (once)

```bash
node -v                     # 18+
npm i playwright && npx playwright install chromium    # headless renderer
ffmpeg -version             # or set FFMPEG=/path/to/ffmpeg
```
Optional overrides: `PLAYWRIGHT_MODULE=<path to playwright or playwright-core>`, `CHROME_PATH=<chrome/chromium executable>`.

**Prove the setup with the demo** (about 1 minute):
```bash
node engine/build.cjs  examples/moonrise
node engine/render.cjs examples/moonrise check          # 8 stills in examples/moonrise/check/
node engine/render.cjs examples/moonrise all            # 60 frames
node engine/render.cjs examples/moonrise timeline
node engine/audio.cjs  examples/moonrise
node engine/encode.cjs examples/moonrise                # film.mp4 (~4MB)
```
If the check stills show a lantern drawn in hatching and a moon over hills with captions in a serif font, everything works. If the captions use a fallback font, the Google Fonts request failed (no network), so fix that before real work.

## 1 · Write the script first (no code yet)

Make a table: `# | time | picture | caption (EN / 中文) | sound`. Rules that made INDEX INFERNO work:
- **One idea per shot, 4–8 s each.** A 45–60 s film is 7–10 shots. Hard cuts with one black pose between shots.
- **The picture carries the metaphor; the caption only names it.** One short line per shot: big English serif, small Chinese underneath.
- **Give the film a direction** (descend then climb, dark then light, closed then open). End on the turn.
- **People: abstract, never portrait.** Mannequins, silhouettes, backs, hands, hooded figures. Detailed faces drawn in code look generic and awkward; abstract figures look like art and let viewers see themselves.
- One accent colour for the whole film (lamp gold), plus at most one symbolic second colour used once.
- Decide the sound events while writing (`lamp`, `chain`, `crack`, `creak`…), because they are part of the storytelling.

Show the script to the person before drawing. It is cheap to change now and expensive later.

## 2 · Project layout

```
my-film/
  shots.js      ← FILM + SHOTS (you write this; split into shotsA.js, shotsB.js… when long, since all *.js get concatenated)
  film.html     ← built
  check/        ← review stills
  frames/       ← p0000.jpg … (8 poses per second)
  timeline.json, audio.wav, film.mp4, film-x.mp4
```
Copy `examples/moonrise/shots.js` as the starting point. Build with `node engine/build.cjs my-film`.

### FILM and SHOTS

```js
const FILM = { title: 'Index Inferno', dur: 58, labels: ['PORTA', 'CIRCVLVS I', …], finale: true };
const SHOTS = [];
SHOTS.push({
  id: 0, t0: 0, t1: 5,               // seconds; shots must tile [0, dur)
  dark: false,                        // true = scratchboard shot (light lines on black; pass col: CHALK to Plates and put a dark rect in `under`)
  cap: [{ a: 0.9, b: 5, en: 'ABANDON ALL CONTEXT…', zh: '入此门者……' }],   // times are local to the shot
  build() { /* build Plates once, store on this */ },
  frame(t) { return { svg, tip, cam?, zoom?, zc?, under? }; },           // t is local; called for every pose
  events() { return [{ t: 3.05, type: 'lamp' }]; },                      // optional sound one-shots, local time
  overlay(t) { return '<svg over the frame border>'; },                  // optional
  blackAt(t) { return false; },                                          // optional extra black flashes
});
```

### Plate: the drawing that writes itself

```js
const P = new Plate(seed, { col: INK, win: [[0,.55],[.22,.72],[.4,.86],[.55,.96],[.66,1],[.3,.9]] });
P.keyFn = (x, y) => x;                        // drawing order within a layer (here: left → right)
P.tone((x, y) => 0..1, { angs, sp, wave, w, con, bb });   // engraved shading: 3 crossing hatch layers (1,2,3), darker = more layers
P.hatch(toneFn, thr, angle, spacing, { layer, bb, wmin, wmax, wave });   // one hatch set, full control
P.line(pts, { w, key, layer, wob, op, col });   // pen contour (layer 0, wobbled by default)
P.poly(pts, o); P.fill(pts, color, o); P.dots(toneFn, n, bb, o); P.text(x, y, str, o); P.raw(svg, o);
const { svg, tip } = P.render(progress0to1);  // tip = [x, y, angle] of the newest stroke → return it so the nib is drawn
```
- `win[layer] = [start, end]` is when that layer draws inside the plate's progress. Contours (0) come first and hatching layers overlap after them, which reads as "sketch, then shade".
- `key` / `keyFn` sets the order within a layer. Sweep in a readable direction (left→right, top→down, outward from the subject).
- **Think in tone functions.** `tone(x, y)` returns 0 for paper white and 1 for the deepest black. Build it from shapes (`pip`, `ell`, `segDist`, `capU`) plus `fbm` noise and `sm` falloffs. Return 0 inside anything that must stay clean (faces of light, the moon, text areas).
- Helpers in `engine/core.js`: `mk(seed)` rng, `fbm`/`vnoise`, `sm`, `clamp`, `lerp`, `ellPts`, `bez`, `spline`, `capsule`, `bbox`, `tf(x, y, s, r)` transform string, `nib()`, `lanternPlate()`, `lanternGlow()`.
- Compose plates by rendering several and wrapping each in `<g transform="${tf(x, y, s)}">`. To animate a thing, re-render it with a transform per frame, or step its position on 8 fps ticks for the hand-drawn feel.
- Camera: return `cam` (vertical pan in px) or `zoom` + `zc` (centre). Keep moves slow and small.

## 3 · Review loop (do not skip)

```bash
node engine/build.cjs my-film && node engine/render.cjs my-film check 12,40,80,120   # pose = seconds × 8
```
Open the stills and actually look at them. Check that:
- each shot reads in one second
- the subject is lit and the hatching doesn't mud it
- the nib is on the newest stroke
- captions don't collide with the drawing
- nothing is empty or crowded

Do at least 3 passes per shot. Crop into details when needed. Fix, rebuild, re-check.

## 4 · Render, sound, encode

```bash
node engine/render.cjs my-film all              # ~0.4 s per pose; a 60 s film = 480 poses. Can resume with: all <from> <to>
node engine/render.cjs my-film timeline         # ink activity per pose + events + cuts
node engine/audio.cjs  my-film                  # drone that sinks shot by shot, pen scratching that follows the ink, events, finale chord
node engine/encode.cjs my-film                  # film.mp4: 1600×900, ~4.8 Mbps (Telegram/WeChat friendly, ~35 MB/min)
node engine/encode.cjs my-film --x --cover 13   # film-x.mp4: 1080p CRF 17 for X; frame at 13 s prepended 0.5 s as the thumbnail
```
Sound events available in `engine/audio.cjs`: `lamp, creak, chain, crack, snap, thud, burn, ash, frost, pull, scoop, release, climb, cut`. Add a new `case` there for anything else. Keep it code-synthesised.

## Hard-won lessons

- **Poses at 8 fps, output at 24 fps.** Grain and pen wobble re-roll every pose, so even held drawings "boil" like hand animation. Don't render 24 unique poses per second: it looks like vector motion graphics.
- **X/Twitter destroys fine hatching + grain.** Always ship `--x`: it is 1080p, CRF 17 and lightly denoised, a big file that survives. X uses the first frame as the thumbnail, so use `--cover <sec>`.
- **Grain makes every frame unique,** so CRF alone gives huge files. The chat version is bitrate-capped on purpose.
- **JPEG frames are full-range.** The encoder converts to TV range; without that, blacks look grey on X.
- **Fonts:** render.cjs preloads every caption glyph. If you add text in plates with other fonts, preload them too.
- **Hatching density:** `sp` 4.4–5.2 px at 1600 wide. Tighter turns to grey mush after compression; wider looks cheap.
- **Draw order is storytelling.** Reveal the subject's contour first, then the shading sweeps; a line that appears late gets looked at.
- **Faces:** keep them to a few strokes, or leave them out (see step 1).
- **Don't trace references.** Borrow the texture of a style (line weight, hatch angle, palette), never the composition.
