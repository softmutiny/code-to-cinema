# code-to-cinema · 代码映画

Films drawn in code. Nothing is generated by an image model: every mark is SVG you wrote, revealed pose by pose. This file is the workflow shared by all styles. **Each style has its own guide with its own shot API, helpers and sound. Read it before you draw anything.**

## Pick a style: starter cards

| | Engraving 铜版画 | Liyue 掐丝珐琅 | Awakening 37号觉醒 |
|---|---|---|---|
| looks like | Doré copperplate: sepia paper, cross-hatching, a pen nib, one warm lamp colour | cloisonné that makes itself: gold wire, enamel cells, glow, guzheng; your own palette | 1920s stop-motion reel: pencil + wash on ivory, poses that jump, labels, one wine red, slam title |
| guide | `styles/engraving.md` | `styles/liyue.md` | `styles/awakening.md` |
| `FILM.style` | (omit) | `'liyue'` | `'awakening'` |
| start by copying | `examples/moonrise/shots.js` | `examples/goldseam/shots.js` | `examples/typewriter/shots.js` |
| shot API | `build()` + `frame(t)` → `{ svg, tip, … }`, `Plate` | `build()` + `frame(t)` → `{ svg, tip, … }`, `Cloi` | `state(q)` + `draw(S, st)` on the DOM, stepped with `key()` |
| sound script | `engine/audio.cjs` | `engine/liyue/audio.cjs` | `engine/awakening/audio.cjs` |
| sound events | `lamp creak chain crack snap thud burn ash frost pull scoop release climb cut` | `pluck chime axe pound drip shatter whoosh bell finale swell` | `type clack tick creak crack thud hiss pop cut thunder slam` |

All three styles render poses at **8 per second** (pose = seconds × 8), at 1600×900.

## 0 · Setup (once)

```bash
node -v                     # 18+
npm i playwright && npx playwright install chromium    # headless renderer
ffmpeg -version             # or set FFMPEG=/path/to/ffmpeg
```
Optional overrides: `PLAYWRIGHT_MODULE=<path to playwright or playwright-core>`, `CHROME_PATH=<chrome/chromium executable>`.
- **If `playwright install` can't download,** get a "Chrome for Testing" build from its public download page (it's served from `storage.googleapis.com`), unzip it, and set `CHROME_PATH` to the chrome executable. An installed Chrome or Edge also works.
- **ffmpeg:** use your package manager (`brew install ffmpeg`, `apt install ffmpeg`), or on Windows a static build (for example from gyan.dev), then set `FFMPEG` if it isn't on PATH.
- **Fonts load from Google Fonts at render time.** If that's blocked, the film still renders, but in fallback fonts. Installing the same families locally (Cormorant Garamond, IBM Plex Mono, Archivo Black, Cinzel, Noto Serif SC, ZCOOL XiaoWei) brings the look back.

Prove the setup by building your style's example (about a minute; swap in `goldseam` + `liyue/audio.cjs` or `typewriter` + `awakening/audio.cjs`):
```bash
node engine/build.cjs  examples/moonrise
node engine/render.cjs examples/moonrise check          # 8 stills in examples/moonrise/check/
node engine/render.cjs examples/moonrise all
node engine/render.cjs examples/moonrise timeline
node engine/audio.cjs  examples/moonrise
node engine/encode.cjs examples/moonrise                # film.mp4
```
If the captions in the stills use a fallback font, the Google Fonts request failed (no network). The film still works, but fix it (or install the fonts) before real work.

## 1 · Write the script first (no code yet)

Make a table: `# | time | picture | caption (EN / 中文) | sound`.
- **One idea per shot.** Shot length by film length:
  - Under 15 s: 2–3 shots of 3–5 s.
  - 30–60 s: 6–10 shots of 4–8 s.
  - Each shot needs its "making" time (1.5–3 s of the picture drawing itself or settling) plus about 1.5 s for the caption to be read.
- **The picture carries the metaphor; the caption only names it.** One short line per shot: English, with Chinese underneath.
- **Give the film a direction** (down then up, dark then light, closed then open, made then broken then mended). End on the turn.
- **People: abstract, never portrait.** Mannequins, silhouettes, backs, hands, dolls, wire ghosts. Faces drawn in code look generic; abstract figures look like art.
- **Colour:** engraving and awakening have fixed palettes with one accent colour (each guide names it); liyue keeps only the gold wire fixed, so choose its enamel palette for your story.
- Decide the sound events while writing, from your style's list above.
- **Invent your own subject.** The examples show technique, not content to reuse.

If there is a person to work with, show them the script before drawing: it is cheap to change now and expensive later.

## 2 · Project layout

```
my-film/
  shots.js      ← FILM + SHOTS (split into shotsA.js, shotsB.js… when long: every *.js is concatenated, shots.js first)
  motif.json    ← optional, liyue only: where the guzheng phrases go
  film.html     ← built
  check/        ← review stills
  frames/       ← p0000.jpg … (8 poses per second)
  timeline.json, audio.wav, film.mp4, film-x.mp4
```
Copy your style's example and build with `node engine/build.cjs my-film`.
- `FILM` must be declared with `const FILM = { title, style?, dur, … }`. The builder reads `title` and `style` from that object, and an unknown style is an error.
- Shots must tile `[0, dur)` with no gaps.
- **Your own gradients, filters and clipPaths** are allowed in every style: put a `<defs>…</defs>` in the SVG you return (or `frag(S, '<defs>…</defs>')` in awakening). Give ids a per-shot prefix, since two shots can be on screen at once during dissolves.

## 3 · Review loop (do not skip)

```bash
node engine/build.cjs my-film && node engine/render.cjs my-film check 12,40,60   # 640 px stills, pose = seconds × 8
node engine/render.cjs my-film full 40                                           # one 1600×900 still, for crops and fine detail
```
Open the stills and actually look at them. Check that:
- each shot reads in one second
- the subject is lit and not muddied
- captions don't collide with the drawing
- nothing is empty or crowded
- the style-specific checks in your guide pass (engraving: the nib is on the newest stroke)

Two things that look like bugs but aren't: captions type in letter by letter, so an early pose shows half a line; and the last pose of a shot is often a black cut pose, so don't pick it for a check. Do at least 3 passes per shot, and look at a full-size still before the final render: fine-line problems don't show at 640 px.

## 4 · Render, sound, encode

```bash
node engine/render.cjs my-film all              # ~0.3 s per pose; can resume with: all <from> <to>
node engine/render.cjs my-film timeline         # events, cuts, activity → timeline.json
node engine/<your style's audio script> my-film # see the starter card
node engine/encode.cjs my-film                  # film.mp4: 1600×900, ~4.8 Mbps (Telegram/WeChat friendly, ~35 MB/min)
node engine/encode.cjs my-film --x --cover 13   # film-x.mp4: 1080p CRF 17 for X (~200+ MB/min); frame at 13 s prepended as the thumbnail
```
The audio scripts warn about event names they don't know (those would be silent). To add a sound, add a `case` in your style's audio script, and keep it code-synthesised.

## Hard-won lessons

- **Poses at 8 fps, output at 24 fps.** Grain and line wobble re-roll every pose, so even held drawings "boil" like hand animation. Don't render 24 unique poses per second: it looks like vector motion graphics.
- **X/Twitter destroys fine lines and grain.** Always ship `--x` for X: 1080p, CRF 17, lightly denoised. X uses the first frame as the thumbnail, so use `--cover <sec>`.
- **Grain makes every frame unique,** so CRF alone gives huge files. The chat version is bitrate-capped on purpose.
- **JPEG frames are full-range.** The encoder converts to TV range; without that, blacks look grey on X.
- **Fonts:** the renderer preloads caption glyphs. List any other Chinese text and unusual symbols (drawn inside the picture) in `FILM.text` so they're preloaded too; a glyph that isn't preloaded may fall back to another font, so check text at full size.
- **Randomness must hold still.** Seed every random choice (`mk(seed)`) unless you want it to re-roll each pose; `Math.random()` makes drawings jump.
- **Flat vector art is the failure mode of every style.** If a still looks like clean clip-art, add the style's texture: engraving tone and hatching, liyue wire and flood, awakening's `pencil`/`wash` filters with hatch patterns at 0.6–0.9 opacity.
- **Draw order is storytelling.** Reveal the subject first; a line that appears late gets looked at.
- **Don't trace references.** Borrow the texture of a style (line weight, palette, rhythm), never a composition.
